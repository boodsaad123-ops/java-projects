# 🎯 Guess Game

A console number guessing game written in Java.

## How it works
- The program picks a random number between 1 and 100.
- You have 5 attempts to guess it.
- After each guess, you get a hint: too high or too low.
- At the end, you can choose to play again (Y/N).

## Concepts used
- `Scanner` for user input
- `Math.random()`
- `do-while` and `while` loops
- `if / else if / else` conditions

## How to run
```bash
javac GuessGame.java
java GuessGame
```

# Grade Checker

A console program that converts a score into a letter grade in Java.

## Grading rules
- Above 100 or below 0: invalid score (the number must be between 0 and 100)
- 90 and above: A
- 80 to 89: B
- 70 to 79: C
- 60 to 69: D
- Below 60: F

## Concepts used
- `Scanner` for user input
- `if / else if / else` conditions
- Logical OR (`||`)

## How to run
```bash
javac GradeChecker.java
java GradeChecker
```

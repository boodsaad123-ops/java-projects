# Leap Year Checker

A console program that checks whether a year is a leap year in Java.

## Rules used
- Divisible by 400: leap year
- Divisible by 100 (but not 400): not a leap year
- Divisible by 4: leap year
- Otherwise: not a leap year

## Concepts used
- `Scanner` for user input
- `if / else if / else` conditions
- The `%` (modulo) operator

## How to run
```bash
javac LeapYear.java
java LeapYear
```
